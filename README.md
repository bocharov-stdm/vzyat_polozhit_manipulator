# Радиоуправляемый манипулятор (STM32)

Шестиосевой манипулятор на сервоприводах с беспроводным пультом.
Положение каждого сустава задаётся потенциометром на пульте.

Два проекта STM32CubeIDE (STM32F401CCU6, HAL):

| Папка | Назначение |
|---|---|
| `manipulator_remote/` | Пульт: 6 потенциометров → АЦП → кадр по UART, дисплей 128×160 |
| `manipulator_receiver/` | Приёмник: кадр по UART → 6 каналов ШИМ для сервоприводов |

Связь идёт по USART1 (PA9 TX / PA10 RX, 9600 бод), к нему подключается радиомодуль.

## Протокол

Кадр из 16 байт, отправляется примерно каждые 40 мс:

```
AA 55 06 | CH1_H CH1_L ... CH6_H CH6_L | CRC
```

- `AA 55` — заголовок, `06` — число каналов;
- значения каналов — 12-битные показания АЦП (0..4095), big-endian;
- `CRC` — XOR всех предыдущих байт.

## Пульт

- Потенциометры на PA0–PA5 (ADC1_IN0..IN5). Показания сглаживаются экспоненциальным фильтром.
- Дисплей TFT 128×160 подключён по программному SPI (PB0 CS, PB3 SCK, PB5 SDA, PB6 RST, PB7 RS).

## Приёмник

| Канал | Пин | Таймер |
|---|---|---|
| Servo1 | PA7 | TIM3_CH2 |
| Servo2 | PB0 | TIM3_CH3 |
| Servo3 | PB1 | TIM3_CH4 |
| Servo4 | PB6 | TIM4_CH1 |
| Servo5 | PB7 | TIM4_CH2 |
| Servo6 | PB9 | TIM4_CH4 |

- ШИМ 50 Гц, импульс 1000–2000 мкс. Диапазон и направление настраиваются для каждой сервы
  отдельно (`SERVOx_MIN_US` / `SERVOx_MAX_US`; если поменять их местами, ход инвертируется).
- Сервы движутся плавно: положение за один цикл меняется не больше чем на 50 мкс.
- Индикатор связи на PA6 мигает с частотой 1 Гц, пока приходят корректные кадры.
  Если корректных кадров нет дольше 0,5 с, индикатор гаснет.
